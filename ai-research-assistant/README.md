# AI Research Assistant (RAG + Vector Search)

## Overview
This project implements an AI-powered research assistant that allows users to query documents using semantic search and Retrieval-Augmented Generation (RAG).

## Features
- Semantic document search
- Vector embeddings using Sentence Transformers
- Retrieval-Augmented Generation (RAG)
- FastAPI backend
- Streamlit interactive frontend

## Architecture
1. Documents are split into chunks
2. Chunks are embedded using a transformer model
3. Embeddings are stored in a vector store
4. Queries retrieve relevant chunks
5. AI generates answers using the retrieved context

## Tech Stack
- Python
- FastAPI
- Streamlit
- Sentence Transformers
- Transformers
